# Translate your Grav site with Supertext

This demo shows how editors translate pages **without leaving the Grav admin**. Open a page, click the [Supertext](https://www.supertext.com) button in the editor toolbar and choose the languages.

## What gets translated

- The page content, with *formatting* and links kept in place
- The title, the menu label and the meta description
- Tables, quotes and lists

> [!TIP]
> New translations are saved unpublished, so you can review them before visitors see them.

## How it works

| Step | What happens |
| ---- | ------------ |
| Translate | Supertext translates the page into each language you choose. |
| Review | You check the translation in the editor and publish it. |

Code such as `bin/grav clear` is never translated.
